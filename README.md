# Entity Management Application

A React-based web application for managing entities with a clean and responsive interface.

## Features

- Entity Management
  - Add new entities
  - Delete existing entities
  - List all entities
  - Search entities
- Web Service Operations
- Modern UI with Tailwind CSS

## Technologies Used

- React.js
- React Router DOM
- Tailwind CSS
- Headless UI
- React Icons

## Prerequisites

Before running this project, make sure you have:

- Node.js (v14 or higher)
- npm (v6 or higher)

## Installation

1. Clone the repository:
```bash
git clone https://github.com/Ruthuwamahoro/entity-management-app.git
cd entity-management-app
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```
